Vue I18n Integration ​

This guide explains how to use vue-i18n for internationalization in your FormKit OpenVue project.

Installation ​

Install vue-i18n in your Vue project:

bash
npm install vue-i18n

INFO

Note: Internationalization (i18n) is only required for Output components in FormKit OpenVue. Input components do not require i18n integration.
