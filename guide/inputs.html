Input Components ​

formkit-openvue tries to integrate as much OpenVue inputs as possible.

WARNING

Used inputs by FormKit must be imported global (default).

They are referenced in the startup phase, if FormKit is enabled.

Naming in FormKit ​

Inputs are used in schema with form as prefix and the input name as suffix.

E.g. InputMask -> formInputMask
